================================================================================
DEPLOYMENT STEPS
================================================================================

1. Clone Repository
   git clone <repo-url>
   cd socio-impact-dash

2. Install Dependencies
   composer install
   npm install

3. Environment Setup
   cp .env.example .env
   php artisan key:generate

4. Database Setup
   php artisan migrate:fresh --seed
   
5. Build Frontend
   npm run build

6. Start Development Server (optional)
   composer run dev
   # Access at http://localhost:8000

7. For Production
   Set APP_DEBUG=false in .env
   Run: php artisan config:cache
   Run: php artisan route:cache

================================================================================
KNOWN ISSUES & SOLUTIONS
================================================================================

If you encounter build errors:
1. Clear cache: npm run dev (rebuilds)
2. Check imports: ensure @/components, @/layouts use correct case
3. Verify Inertia: ensure imports from '@inertiajs/react'
4. TypeScript: run npm run build with verbose flag

If migrations fail:
1. Ensure database is created and accessible
2. Check .env DB_* variables
3. Clear config cache: php artisan config:clear
4. Run: php artisan migrate:fresh --seed

If auth errors occur:
1. Clear sessions: php artisan session:flush
2. Verify HasRoles trait in User model
3. Check Spatie config at config/permission.php
